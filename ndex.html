REINFORCEMENT LEARNING CORE

The agent discretizes the continuous game state into bucketed tuples: [Δx_pipe, Δy_gap, velocity]. Using the Bellman Q-Update: Q(s,a) ← Q(s,a) + α [r + γ max Q(s',a') - Q(s,a)] The bird discovers through exploration that flapping too high or dropping too fast results in a severe crash penalty.
